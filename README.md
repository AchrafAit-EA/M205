# PHP & Laravel — Exercices Pratiques

Bienvenue dans mon dépôt GitHub dédié à l'apprentissage et à la pratique du développement web avec **PHP et Laravel**.

Ce repository regroupe mes exercices, travaux pratiques (TP) et mini-projets réalisés dans le cadre de ma formation en Développement Digital — Full Stack.

## 🎯 Objectifs

- Renforcer mes compétences en PHP.
- Maîtriser les concepts fondamentaux de Laravel.
- Apprendre à développer des applications web dynamiques.
- Pratiquer la gestion des bases de données avec MySQL.
- Améliorer mes compétences en programmation et en résolution de problèmes.

## 📚 Contenu du Repository

### 1. PHP
- Variables et types de données
- Conditions et boucles
- Fonctions
- Tableaux
- Programmation Orientée Objet (POO)
- Gestion des formulaires
- Connexion à MySQL avec PDO

### 2. Laravel
- Installation et configuration
- Routes et Controllers
- Blade Templates
- Models et Migrations
- Eloquent ORM
- CRUD Operations
- Validation des formulaires
- Authentication

### 3. Mini-Projets
Petites applications et projets pratiques réalisés pour mettre en application les notions étudiées.
